# OpenGL-village
This is an OpenGL project of a scene with a village. It was part of a semestral work we did in university.

There are three functions missing in the vesnice.cpp file, which is the main function, finalizeApplication function and initializeApplication function, because these are function that were provided to us by the teachers.

Pgr.h is a library provided by the teachers, which contained the OpenGL functions.

Vertex and Fragment shaders are in Shaders directory.
